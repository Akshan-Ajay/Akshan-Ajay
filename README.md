## ✈️ SF Air Traffic Landings Forecasting

**SARIMA Time-Series Forecasting**

<a href="https://github.com/Akshan-Ajay/sarima-air-traffic-forecasting">
  <img src="https://img.shields.io/badge/View%20Project-GitHub-181717?style=for-the-badge&logo=github">
</a>

### 🧰 Technologies

`Python` · `Pandas` · `Statsmodels` · `Matplotlib`

`ARIMA` · `SARIMA` · `Time Series Analysis`

### 📌 Highlights

* Processed **195 months of airport data (2002–2017)**.
* Handled missing values using interpolation.
* Performed **ADF stationarity testing**.
* Used **ACF/PACF analysis** for parameter selection.
* Compared multiple SARIMA configurations.
* Selected **SARIMA(2,1,1)(1,1,1,12)** based on AIC/BIC.
* Generated future forecasts.
* Achieved:

  * **RMSE: 945.53**
  * **MAE: 755.35**
  * Approximately **5% error rate**
* Used the **Ljung-Box test** for residual validation.
